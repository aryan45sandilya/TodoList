## ✨ Features

- 📅 **Month-wise Task Management** — Switch between months and keep tasks organized separately
- ➕ **Add Tasks Instantly** — Type and press Enter or click Add
- ✅ **Mark as Complete** — Checkbox to toggle task status
- 🗑️ **Delete Tasks** — Remove tasks you no longer need
- 🔍 **Filter Tasks** — View All, Pending, or Completed tasks
- 📊 **Live Stats** — Total, Completed, and Pending count always visible
- 💜 **Beautiful UI** — Smooth animations, gradient design, glassmorphism style
- 📱 **Fully Responsive** — Works on mobile, tablet, and desktop

## 🚀 Getting Started

### Run Locally

```bash
# Clone the repository
git clone https://github.com/aryan45sandilya/TodoList.git

# Open in browser
cd TodoList
start index.html
```

No build tools. No dependencies. Just open `index.html` and go. ⚡

## 📦 Deployment

This project is deployed on **Vercel**.

To deploy your own:
1. Fork this repo
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import your forked repo
4. Click **Deploy** — done!
